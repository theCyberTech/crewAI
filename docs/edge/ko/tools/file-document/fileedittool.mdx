# `FileEditTool`

## 설명

`FileEditTool`은 crewai_tools 패키지의 구성 요소로, 정확한 문자열을 교체하여 기존 텍스트 파일을 편집합니다.
파일 전체를 다시 쓰는 대신 에이전트가 변경할 부분과 그 자리에 들어갈 텍스트를 지정하므로, 코드, 설정, 문서에 대한 작고 정밀한 편집을 저렴하고 안전하게 수행할 수 있습니다.
`replace_all`을 설정하지 않는 한 해당 부분은 정확히 한 번만 일치해야 하므로, 모호한 일치로 인해 엉뚱한 위치가 편집되는 일이 없습니다. 줄 끝 문자는 디스크에 있는 그대로 유지되며, 파일은 기본적으로 UTF-8로 읽고 씁니다.

## 설치

프로젝트에서 `FileEditTool`을 사용하려면 crewai_tools 패키지를 설치하세요:

```shell
pip install 'crewai[tools]'
```

## 예시

`FileEditTool`을 시작하는 방법:

```python Code
from crewai_tools import FileEditTool

# Initialize the tool
file_edit_tool = FileEditTool()

# Replace a single, unique snippet
result = file_edit_tool.run(
    file_path='config.yaml',
    old_string='debug: false',
    new_string='debug: true',
)
print(result)

# Rename every occurrence of an identifier
result = file_edit_tool.run(
    file_path='app.py',
    old_string='old_name',
    new_string='new_name',
    replace_all=True,
)
```

`FileReadTool`과 함께 사용하면 에이전트가 먼저 파일을 읽고 교체하려는 정확한 텍스트를 복사할 수 있습니다:

```python Code
from crewai import Agent
from crewai_tools import FileEditTool, FileReadTool

editor = Agent(
    role="Code Editor",
    goal="Make precise, minimal edits to project files",
    backstory="You read a file before changing it and only touch the lines that need to change.",
    tools=[FileReadTool(), FileEditTool()],
)
```

## 인자

에이전트가 런타임에 제공하는 값:

- `file_path`: 편집할 기존 파일의 경로입니다. 상대 경로는 도구의 허용된 디렉터리 내부에서 해석됩니다.
- `old_string`: 교체할 정확한 텍스트로, 공백과 들여쓰기를 포함합니다. `replace_all`이 true가 아닌 한 정확히 한 번만 나타나야 하며, 고유하게 만들려면 주변 줄을 포함하세요.
- `new_string`: 교체할 텍스트입니다. `old_string`과 달라야 합니다. `old_string`을 삭제하려면 빈 문자열을 전달하세요.
- `replace_all` (선택 사항): 모든 일치 항목을 교체할지 여부입니다. `true`/`false`(또는 `yes`/`no`, `on`/`off`, `1`/`0`)를 허용합니다. 기본값은 `false`이며, 이 경우 `old_string`이 두 번 이상 나타나면 오류를 보고합니다.

도구를 생성할 때 설정하는 값:

- `base_dir` (선택 사항): 편집이 머물러야 하는 디렉터리입니다. 기본값은 현재 작업 디렉터리입니다.
- `encoding` (선택 사항): 파일을 읽고 쓸 때 사용하는 텍스트 인코딩입니다. 기본값은 `utf-8`입니다.

이 도구는 기존 파일만 편집합니다. 파일을 생성하거나 전체 내용을 교체하려면 [`FileWriterTool`](/ko/tools/file-document/filewritetool)을 사용하세요.

## 허용된 경로

파일 경로는 보통 런타임에 LLM이 선택하므로, 편집은 샌드박스 내로 제한됩니다. 해석된 `file_path`는 `base_dir`(기본값은 현재 작업 디렉터리) 내부에 있어야 합니다. `..` 세그먼트, 절대 경로, 심볼릭 링크는 검사 전에 해석되므로 이를 이용해 벗어날 수 없습니다.

에이전트가 작업 디렉터리 밖을 편집하도록 허용하려면 `base_dir`을 대상 트리로 지정하세요:

```python Code
# The agent may edit anywhere under /srv/app, and nowhere outside it
file_edit_tool = FileEditTool(base_dir='/srv/app')
```

<Note>
    `CREWAI_TOOLS_ALLOW_UNSAFE_PATHS=true`를 설정하면 경로 검증이 비활성화되지만, 이는 URL을 가져오는 도구의 SSRF 보호를 포함하여 프로세스 전체의 모든 crewai-tools 도구에 적용되므로 `base_dir` 사용을 권장합니다.
</Note>
